# webNBT
**An HTML5 NBT-editor based on emscripten** (Created by [iRath96](https://github.com/iRath96/webNBT))

Allows you to edit NBT-files saved by Minecraft directly in your browser - no need to download anything!

Check out the [live-demo](http://irath96.github.io/webNBT/).


# NBTEditor

A fork of **webNBT** embedded in an [Electron](https://www.electronjs.org/) for offline convenience.
